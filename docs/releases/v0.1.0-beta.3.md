# OpenGEO 0.1.0-beta.3

A clearer workspace for following an answer from its source to your next website improvement.

## What changed

- Consistent navigation, typography, page layouts and keyboard-accessible dialogs across the app.
- Visibility charts keep incomplete checks separate from zero results, with readable labels and an accessible data table.
- Responses open with their full text and source links. Sources show coverage and searchable domains.
- Site Audit adds page search, unavailable-page filtering, headings and structured-data details.
- Opportunities explain which evidence is missing and offer the next useful step.
- Content separates drafts needing review and keeps editing, sources and versions together.
- Competitors include your site's citation benchmark. Reports explain the saved evidence and backup contents.
- Settings provides clearer connection, privacy, schedule and update guidance.
- Security updates for request parsing, URI handling, HTTP requests, schema validation and the desktop runtime.

## Install and update

Choose your platform from the [downloads](https://github.com/surfacedby/OpenGEO/releases/tag/v0.1.0-beta.3).
Export a backup from Settings, quit OpenGEO from the tray, then install the update.
Updates are manual. Your workspace remains in its application data directory;
backup exports exclude credentials. See the [installation guide](../distribution.md).

Windows packages are unsigned. Mac packages are ad hoc signed, without Developer ID
signing or notarization. Your operating system may block installation. Mac updates
can require approval for OpenGEO Safe Storage in the system Keychain dialog.
Checksums identify the published files; they do not replace publisher signing.

Projects and encrypted connections stay local. Usage sharing is optional.
External providers can charge for requested work. Managed supplier quality,
billing recovery and production activation remain separate acceptance gates;
this beta does not certify them. Private-network access is for protected networks,
not unprotected public hosting.
