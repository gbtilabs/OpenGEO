# OpenGEO 0.1.0-beta.1

OpenGEO's first downloadable beta brings the local AI visibility workspace to Windows x64. The installer includes its runtime and browser; no developer tools are needed to use the desktop app.

## Downloads and installation

Use the assets on the [official GitHub release](https://github.com/surfacedby/OpenGEO/releases/tag/v0.1.0-beta.1). Check the installer's SHA256 against the accompanying `SHA256SUMS.txt`. The `release-manifest.json` records the exact source commit, artifact hashes and verification scope.

**The Windows installer is unsigned.** Windows can display unknown-publisher or SmartScreen warnings. Some managed computers will block it. Signing and store distribution are deferred; this is not a signed stable v1 release. Read [distribution instructions](../distribution.md) before installing. Updates are manual.

macOS and Linux desktop binaries are not included. [Source and Docker instructions](../../README.md#run-locally) remain available; the Docker path builds locally rather than pulling a published OpenGEO image.

## What you can try

- Add websites and run local audits without an AI provider.
- Keep page evidence, projects, drafts and schedules in a local workspace.
- Connect an eligible ChatGPT plan or your own supported providers for answer checks, analysis and content. Provider permissions, limits and charges apply; OpenGEO does not grant access or make their usage free.
- Inspect the collected answers and sources instead of treating an observed mention or citation as a ranking guarantee.
- Export projects and backups without exporting provider credentials.

## Privacy and operating limits

During first setup, optional usage sharing is preselected. Uncheck it before finishing setup, or turn it off later in Settings, if you do not want to share activity counts. See [privacy](../privacy.md) for the fields and destinations. The packaged local verification explicitly disables sharing.

SQLite and encrypted credentials remain local. Keep the workspace private and export a backup before future updates. Closing the window leaves OpenGEO in the tray; use Quit to stop it. Scheduled work runs while the app is open, and a selected external provider can charge for scheduled calls.

SurfacedBy managed operations remain experimental and depend on the connected server's advertised capabilities. This beta does not establish live supplier quality/cost, settlement/refund/cancellation/recovery, production worker-policy agreement, deployed usage-to-admin delivery or historical-import acceptance. No automatic paid fallback is provided.

Unsigned download warnings, clean-machine certification and cross-version upgrade coverage remain limitations. Report reproducible problems through [GitHub issues](https://github.com/surfacedby/OpenGEO/issues). Use the repository's [security policy](../../SECURITY.md) for private vulnerability reports, and remove credentials, customer data and private workspace files from any report.
