# OpenGEO 0.1.0-beta.1

The first OpenGEO public beta is available for Windows, Apple Silicon Macs and Intel Macs. Audit your website, check how AI answers mention your brand, and keep the evidence and improvement work in one local workspace.

[Download the beta](https://github.com/surfacedby/OpenGEO/releases/tag/v0.1.0-beta.1) | [Installation guide](../distribution.md) | [First steps](../getting-started.md)

## Start with your website

- Audit public pages without an AI account.
- Track the questions your customers ask, then inspect brand mentions and website citations in collected answers.
- Review cited sources and evidence-supported competitors.
- Plan page updates or new resources, then develop briefs and drafts with their sources attached.
- Save projects, export your work and make backups on your own computer.

AI features need an [eligible connected service](../connections.md). Provider permissions, usage limits and charges apply. OpenGEO does not make external AI usage free, and it never silently switches you to a paid provider. Measurements are observations, not a promise of rankings or growth.

## Choose your download

| Platform | Package | Current verification |
| --- | --- | --- |
| Windows x64 | `.exe` installer | Install, local audit, backup, reinstall with data retention and uninstall on an isolated maintainer profile |
| Mac Apple Silicon | `macos-arm64.dmg` | Actual mounted-and-copied installation, local workflow and strict ad hoc resource-seal checks on macOS 15 |
| Mac Intel | `macos-x64.dmg` | Actual mounted-and-copied installation, local workflow and strict ad hoc resource-seal checks on macOS 15 |

The packages include the runtime and browser. Source and [Docker installation](../distribution.md#docker) are also available; Docker builds locally. There is no Linux desktop package in this beta.

**Windows is unsigned. Mac packages are not Developer ID signed or notarized.** Your operating system or organization may block them. Follow the [platform instructions](../distribution.md) and verify the checksums before installation. Older macOS versions, clean-machine installation, browser-quarantine installation and cross-version upgrades are not certified. This is not a signed stable v1.

## Data and daily use

Your projects live in local SQLite storage; credentials are encrypted separately. Keep the workspace private and export a backup before updating. Project exports exclude provider credentials.

Optional usage sharing is preselected in setup. Uncheck it before finishing, or turn it off in Settings. It shares activity counts, not websites, prompts, answers or credentials. [Privacy details](../privacy.md).

Updates are manual. Closing the window leaves OpenGEO in the tray; **Quit** stops it. Schedules run while the app is open, and selected providers can charge for scheduled work.

## Managed features

SurfacedBy API features remain experimental and depend on the server's advertised capabilities. This desktop beta does not certify live supplier output or cost, charge/refund/cancellation recovery, worker-policy activation, deployed usage delivery or historical imports. Local package tests do not establish those separate acceptance requirements.

## Release verification and feedback

The exact application source passed 142 local tests and the five-platform application CI. The downloadable payloads received exact-file provenance and confidentiality review, with no unresolved findings. Published hashes were checked against complete anonymous downloads. This is evidence for the tested beta scope, not clean-machine or stable-release certification.

All binaries and the source ZIP correspond to source commit `3ba6ed4f317a88efa18a7db9c4c4f372e486c6b9`. Later repository commits improve release tooling and documentation. `release-manifest.json` and `SHA256SUMS.txt` on the release page identify the files.

[Report a reproducible bug](https://github.com/surfacedby/OpenGEO/issues) with your app version, operating system and steps. Remove credentials and private project data. Use the [security policy](../../SECURITY.md) for vulnerability reports.
