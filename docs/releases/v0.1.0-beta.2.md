# OpenGEO 0.1.0-beta.2

Use OpenGEO on your own computer, or reach a self-hosted workspace over your
private network with an explicit HTTPS origin and a workspace access key.

## What changed

- Optional authenticated private-network access for self-hosters, including
  Tailscale Serve. See [remote access](../remote-access.md).
- Configurable Docker ports and complete SSH tunnel instructions.
- Headless connection flows for ChatGPT and OpenRouter. Existing provider
  eligibility and billing still apply.
- Session expiry keeps unsaved work visible while you sign in again.
- Desktop app and OAuth listeners stay on loopback even if container settings
  were inherited from the launching shell.
- Startup failures close listeners and release the workspace lock.

## Install and update

Choose Windows x64, Apple Silicon or Intel Mac from the
[beta downloads](https://github.com/surfacedby/OpenGEO/releases/tag/v0.1.0-beta.2).
Updates are manual: quit OpenGEO, back up your workspace from Settings, and install
the new version. Your existing local workspace stays in its application data
directory. See the [installation guide](../distribution.md).

Windows downloads are **unsigned**. Mac downloads have a verified **ad hoc resource
seal**, without an Apple Developer ID or notarization; macOS may block the first
launch. These are beta downloads, not store-certified applications. Checksums
identify the reviewed files and do not replace publisher signing.

Projects and encrypted connections stay local. Backup exports exclude credentials.
Usage sharing is optional. Provider usage can incur external charges; this release
does not claim new paid-provider, managed billing or production activation
acceptance. Remote mode is for a protected private network, not public hosting.
